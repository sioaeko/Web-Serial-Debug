설정은 현재 브라우저에 저장됩니다. 시크릿 모드에서는 창을 닫으면 초기화됩니다.

사용자 스크립트

수신 데이터를 처리하거나 명령을 자동화합니다. 직접 확인한 코드만 실행하세요.

스크립트 메시지 규격

uart_receive 수신 이벤트
uart_send 바이트 배열 전송
uart_send_txt UTF-8 텍스트 전송
uart_send_hex HEX 문자열 전송
log 시스템 로그 표시

스크립트는 네트워크 요청을 수행할 수 있습니다. 출처를 모르는 코드는 실행하지 마세요.

연결부터 전송까지

  1. USB 케이블로 장치를 연결하고 포트 선택을 누릅니다.
  2. 장치에 맞는 통신 속도와 옵션을 선택한 후 연결하기를 누릅니다.
  3. 장치 출력은 로그에서 확인하고, 아래 입력창에서 데이터를 전송합니다.

Arduino 시리얼 모니터 등 다른 프로그램이 포트를 사용 중이면 먼저 연결을 해제하세요. USB-UART 드라이버가 필요한 장치는 제조사 드라이버를 설치해야 합니다.

한글이 깨져 보이나요?

수신 인코딩을 UTF-8 또는 EUC-KR (CP949)로 바꿔 보세요. 텍스트 전송은 UTF-8입니다. 다른 송신 인코딩이 필요한 경우 해당 바이트를 HEX로 전송하세요.

macOS에서는 Ctrl 대신 ⌘ Command를 사용하세요. 한글 조합 중에는 전송 단축키가 작동하지 않습니다.

지원 환경과 개인정보

데스크톱 Chrome·Edge와 HTTPS 또는 localhost 환경에서 사용하세요. Firefox·Safari·대부분의 모바일 브라우저에서는 실제 시리얼 연결을 지원하지 않습니다.

로그는 메모리에만 보관되고 설정·전송 기록은 이 브라우저에 저장됩니다. 사이트에는 분석·추적 스크립트가 없습니다. 로그와 설정을 공유하기 전 비밀번호나 장치 식별 정보가 없는지 확인하세요. 사용자 스크립트는 별도 네트워크 요청을 할 수 있으므로 신뢰하는 코드만 실행하세요.
